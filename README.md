# claude-rules — 내 프로젝트 공통 규칙 원본

민정의 모든 프로젝트가 공유하는 **Claude Code 작업 규칙의 "원본 노트"**.
새 프로젝트는 여기서 규칙을 가져가 시작하고, 규칙이 바뀌면 여기서 고쳐 각 프로젝트에 퍼뜨린다.

## 📂 파일

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | **공통 규칙 원본.** 최우선 규칙 + 응대 방식 + 작업 규칙(자동 머지 등). 규칙 변경은 여기서. |
| `template.md` | **새 프로젝트용 CLAUDE.md 양식.** 공통 규칙 + 「채워넣기」 칸(프로젝트 고유 부분). |

## 🚀 새 프로젝트 시작할 때 (프로젝트당 딱 한 번)

그 프로젝트 레포로 새 Claude Code 창을 열고 이렇게 말한다:

> "이 레포에 CLAUDE.md 만들어줘. 공통 규칙은 `claude-rules`의 것과 똑같이 하고,
> 배포·코드 구조 같은 프로젝트 고유 부분은 이 레포를 분석해서 채워줘."

→ 한 번 만들어두면, 그 뒤 그 레포의 모든 새 창은 자기 `CLAUDE.md`를 자동으로 읽는다. (매번 명령할 필요 없음)

## 🔁 규칙을 바꿨을 때

- **새 규칙을 원본에 반영**: 이 `claude-rules` 레포 창에서 "이 규칙 추가해줘" → `CLAUDE.md`(+필요시 `template.md`) 업데이트.
- **기존 프로젝트에도 적용**: 그 프로젝트 레포 창에서 "공통 규칙을 `claude-rules` 최신으로 동기화해줘."
- **새로 시작하는 프로젝트**: 자동으로 최신 규칙으로 시작(위 "새 프로젝트" 절차).

## ℹ️ 메모

- 이 레포는 **공개(public)로 두는 걸 권장.** 규칙엔 비밀값이 없고, 다른 세션에서 가져오기가 쉬워진다.
- 핵심 원칙: **"한 곳 고치면 모든 곳 자동"은 아니다.** 새 프로젝트는 자동으로 최신을 따라가지만, 이미 만든 프로젝트엔 "동기화해줘"라고 한 번씩 말해야 반영된다.

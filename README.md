# project-starter — 새 프로젝트 시작점 + 공통 규칙 원본

민정의 모든 프로젝트가 공유하는 **Claude Code 작업 규칙의 원본**이자, 새 프로젝트를 만들 때 쓰는 **템플릿 레포**다.

## 🚀 새 프로젝트 시작 (매번)

1. GitHub에서 이 레포(`project-starter`) 페이지로 간다.
2. 초록색 **"Use this template" → "Create a new repository"** 클릭.
3. 새 프로젝트 이름을 정하고 만든다.
4. `claude.ai/code`에서 그 새 레포로 창을 열고 한마디("이 프로젝트 세팅 시작하자")만 하면,
   Claude가 `CLAUDE.md`의 "첫 세팅" 지시대로 **〔채워넣기〕 채우기 + 이 README 교체 + 중복 파일 정리**를 알아서 한다.

> 한 번 만들어두면 그 레포의 모든 새 창은 자기 `CLAUDE.md`를 자동으로 읽는다. (이름·규칙을 매번 기억할 필요 없음)

## 🔧 (최초 1회) 템플릿으로 지정

이 레포 **Settings → "Template repository" 체크박스 ✅** 를 켜야 "Use this template" 버튼이 나온다.

## 🔁 규칙을 바꾸고 싶을 때

- **원본 수정**: 이 레포 창에서 "이 규칙 추가해줘" → `CLAUDE.md`(공통 규칙)를 고친다. → 이후 새 프로젝트는 자동으로 최신 규칙으로 시작.
- **이미 만든 프로젝트에도 반영**: 그 프로젝트 레포 창에서 "공통 규칙을 `project-starter` 최신으로 동기화해줘."

## 📂 파일

| 파일 | 역할 |
|---|---|
| `CLAUDE.md` | 공통 규칙 원본 + 새 프로젝트 템플릿(겸용). 규칙 변경은 여기서. |
| `README.md` | 이 설명서. |

## ℹ️ 메모

- 이 레포는 **공개(public)** 권장 — 규칙엔 비밀값이 없고, 다른 세션에서 가져오기 쉬워진다.
- "한 곳 고치면 모든 곳 자동"은 아니다: **새 프로젝트는 자동으로 최신**을 따라가지만, **이미 만든 프로젝트엔 "동기화해줘"라고 한 번씩** 말해야 반영된다.
